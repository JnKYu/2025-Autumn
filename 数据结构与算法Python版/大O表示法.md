### 从代码分析确定执行时间数量级函数
1. 代码赋值语句分为四部分

   $T(n) = 3+3n^2+2n+1 = 3n^2+2n+4$
   ```python
   a = 5                    # 3
   b = 6
   c = 10
   for i in range(n):       # 3n^2
     for j in range(n):
         x = i * i
         y = j * j
         z = i * j
   for k in range(n):       # 2n
       w = a* k + 45
       v = b * b
   d = 33                   # 1
   ```
2. 仅保留最高阶项$n^2$，去掉所有系数
3. 数量级为$O(n^2)$
