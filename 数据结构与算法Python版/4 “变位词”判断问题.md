# “变位词”判断问题

- 问题描述
  - “变位词”指两个词之间存在*组成字母的重新排列*关系
  - 为了简化问题，假设参与判断的两个词仅由小写字母构成，而且长度相等
  
- 解题目标
  - 写一个bool函数，以两个词s1、s2为参数，返回这两个词是否变位词

- 可以很好战士统一问题的不同数量级算法

### 解法1:逐字检查
- 解法思路：对s1中的每个字符分别检查，看s2中是否有出现，出现则“打勾”处理
  - 如果每个字符都被找到，则是变位词
  - 如果存在一个字符不被找到，则不是变位词
 
- 程序技巧
  - 将s2对应字符设为None
  - 由于str是不可变类型，需要先复制到list中
 
- 相应代码
  ```python
  def anagramSolution1(s1, s2):
      alist = list(s2)   # 复制s2到列表
      pos1 = 0
      stillOK = True
      while pos1 < len(s1) and stillOK:   # 循环s1的每个字符
          pos2 = 0 
          found = False
          while pos2 < len(alist) and not found:
              if s1[pos1] == alist[pos2]: # 在s2逐个对比
                  found = True
              else:
                  pos2 = pos2 + 1
          if found:
              alist[pos2] = None     # 找到，打勾
          else:
              stillOK = False        # 未找到，失败
          pos1 = pos1 + 1
      return stillOK
  
  print(anagramSolution1('abcd','dcba'))
  ```
- 问题规模：词中包含的字符个数n
- 主要部分在于两重循环
  - 外层循环
  - 内层循环
- 数量级为 1+2+...+n -> $O(n^2)$

### 解法2:排序比较
- 解法思路：将两个字符串都按照字母顺序排好序，再逐个字符对比是否相同
  - 如果相同则是变位词
  - 有任何不同就不是变位词
  
- 相应代码
  ```python
  def anagramSolution2(s1, s2):
    alist1 = list(s1)          # 转为列表
    alist2 = list(s2)

    alist1.sort()              # 分别排序
    alist2.sort()

    pos = 0
    matches = True
    while pos < len(s1) and matches:
        if alist1[pos] == alist2[pos]:   # 逐个对比
            pos += 1
        else:
            matches = False

    return matches
  
  print(anagramSolution2('abcde', 'edcba'))   
  ```
- 粗看数量级为 $O(n)$
  - 但排序前的两个sort并不是无代价的
  - 两行 sort() 各花 O(n log n) 时间、O(n) 额外空间；
    
    后面的 while 循环只占 O(n) 时间和 O(1) 空间，成本可忽略。
- 本算法时间主导的步骤是排序步骤
- 本算法的运行时间数量级就等于排序过程的数量级O(n log(n))
