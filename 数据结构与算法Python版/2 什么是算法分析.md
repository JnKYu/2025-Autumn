# 什么是算法分析

### 一、算法分析的概念
1. 比较程序的好坏：代码风格、可读性等
2. 算法本身特性
3. 算法分析：从计算资源损耗角度

### 二、代码风格和可读性
- Python强制缩进

### 三、计算资源指标
1. 所需存储空间（或内存）
2. 算法执行时间
  - 运行时间检测
    - Python的time模块
      ```python
      import time
      time.time()
      ```
      ```python
      start = time.time()  # 检测累计时间
      end = time.time()
      ```
注：我们需要更好的方法来衡量算法的运行时间，这个指标与具体的机器、程序和运行时段都无关
