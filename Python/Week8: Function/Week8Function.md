### **代码模块化**

* **目的**：帮助管理复杂的程序，提高代码的重用性和可读性。
* **Python中的方法**：函数、模块、包和类。

### **函数（函数）**

* **通用用途**：函数用于多次执行一块语句，帮助减少冗余代码并简化程序。
* **类型**：内建函数和用户定义的函数。
* **函数定义**：

  * 以 `def` 关键字开头，后跟函数名和参数（如果有）。
  * 可选地包括文档字符串（docstring）。
  * 可以使用 `return` 语句返回一个值，若不返回值，则返回 `None`。

### **内建函数**

* 示例包括 `abs()`、`min()`、`max()`、`divmod()`、`len()` 等。
* Python解释器提供的函数，始终可用。

### **用户定义的函数**

* **定义**：用户为执行特定任务而定义的函数。
* **语法**：

  ```python
  def function_name(parameters):
      """文档字符串"""
      # 函数体
      return value
  ```
* 可以返回多个值（例如使用元组）并接受任何数据类型作为参数。

### **调用函数**

* 语法：`function_name(arg1, arg2, ...)`
* 传入的参数必须与函数定义中的参数一一对应。
* 函数必须在调用之前定义。

### **位置参数和关键字参数**

* **位置参数**：按照定义的顺序传递参数。
* **关键字参数**：通过参数名传递参数，允许灵活调整顺序。

### **传递可变和不可变对象作为参数**

* **不可变对象**：函数内部的改变不会影响原始对象（如整数、字符串、元组）。
* **可变对象**：函数内部的改变会修改原始对象（如列表、字典）。

### **带默认值的参数**

* 你可以为参数定义默认值，使其在调用时成为可选参数。

### **可变参数（`*args` 和 `**kwargs`）**

* **`*args`**：传递一个可变长度的非关键字参数元组。
* **`**kwargs`**：传递一个可变长度的关键字参数字典。

### **命令行参数**

* Python程序可以通过 `sys.argv` 获取命令行传入的参数。

### **变量的作用域和生命周期**

* **全局作用域**：在程序中可以访问和修改的变量。
* **局部作用域**：只在函数内部有效的变量。
* **global 关键字**：允许在函数内修改全局变量。

### **递归（递归）**

* 函数通过调用自身来解决同一问题的简化版本。
* 示例包括计算从 1 到 N 的和或计算阶乘。

### **匿名函数（Lambda表达式）**

* 使用 `lambda` 定义的内联函数，用于执行简单任务。
  示例：

  ```python
  g = lambda a, b: 3*a + b**2
  ```

### **使用 `filter()` 和 `map()` 函数**

* **`filter()`**：基于条件过滤序列中的元素。
* **`map()`**：将一个函数应用于序列中的每个元素。

### **模块和包**

* **模块**：包含函数和变量的 Python 文件（扩展名为 `.py`）。
* **包**：包含多个模块的目录，通常有一个 `__init__.py` 文件。

### **安装第三方模块**

* 使用 `pip` 或 `conda` 安装外部 Python 包，如 Pandas。

### **`main()` 函数**

* 用于定义程序的主逻辑，是直接执行文件时的入口点。
* 特殊的 `__name__` 变量用于区分直接执行和作为模块导入的情况。
